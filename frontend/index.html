manga-dl — Read & Download Manga from 50+ Sources, Free

manga-dl is a free, open-source manga reader for web, desktop, and Android. Stream from 50+ sources, download for offline reading, and sync progress with AniList and MyAnimeList. No ads. No DRM. No paywalls.

Features

50+ Sources

MangaDex, AsuraScans, MangaKatana, Bato.to, MangaPlus, TCBScans, MangaPill, Webtoons, and many more — all in one interface.

Read Offline

Download entire series as CBZ or EPUB. Read anywhere, no internet connection required.

Tracker Integration

Sync reading progress automatically with AniList, MyAnimeList, Kitsu, MangaUpdates, Shikimori, and Bangumi.

3 Platforms

Web PWA, native desktop app via Tauri (macOS, Windows, Linux), and a native Android APK. One library everywhere.

Cross-Device Sync

Reading progress, library, and notes sync across all your devices via encrypted cloud storage.

No Ads. No DRM.

Open source, zero paywalls. Your manga library and data stay yours, forever.
